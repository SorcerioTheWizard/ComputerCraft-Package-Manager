# Add CCPM to Awesome-cctweaked

Get CCPM listed in [awesome-cctweaked](https://github.com/Shlomo1412/awesome-cctweaked), the actively maintained curated list of CC: Tweaked libraries, programs, and tools (about 100 entries, 33 stars, pushed within the last week as of 2026-09-29).

## What to do

1. Read the list's contribution rules and entry format before editing; match how existing entries are written, including any badges.
2. Open a pull request adding CCPM to the most fitting section, which is likely the tools or programs section rather than libraries.
3. Link the main repository, [ComputerCraft-Package-Manager](https://github.com/SorcerioTheWizard/ComputerCraft-Package-Manager), not the registry.

## Suggested entry text

Keep it to one line, matching the list's style, for example: "CCPM: a package manager with dependency resolution, a one command installer, and every Pinestore project installable by name."

## Notes

- The list is also a good source of authors to invite to publish natively in the registry, since each entry links a real project.
- The list links to projects rather than hosting installable packages, so it is not a candidate for a sync adapter.
